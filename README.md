# Проектные решения

## Структуры данных 

FileInfo - основная запись о файле, содержит список хэш-блоков, полный путь и методы для сортировки и сравнения списка хэш-блоков
Структура добавляется в FileInfoSet_t для отсортированности по пути к файлу
FileInfoSet_t добавляется в FilesCollection_t (unordered_map<file_sz_t, FileInfoSet_t>)  по размеру файла.

## Принципиальное описание алгоритма

1. На первом шаге происходит поиск всех файлов в указанных каталогах и заполнение коллекции с типом FilesCollection_t.
В итоге получится, что для каждого размера файла будет свое множество файлов, отсортированных по имени. 
Если множество состоит только из одного элемента - такой элемент удаляется. 
Файлы нулевого размера считаются идентичными по определению.

2. На втором шаге для каждого размера файла производится проход по множеству с вычислением хэш-блоков и их сравнением.
